# 실제 OCR 시험 피드백과 보수적 공백 처리

2026-11-13 사용자 보고: 기존 0.3 포터블과 실제 Windows 게임에서 약 1279×725 영역은 배경 문자가 섞였으며 약 900×70 대사 영역에서는 한 문장이 의미에 맞게 인식됐으나 일본어 단어 사이 공백이 남았다. 게임 대사/이미지는 수집하거나 이 문서에 포함하지 않았다. 오프라인 데모 자막은 확인됐으나 게임 위 클릭 통과와 실제 번역은 미검증이다. 이 기록은 사용자 보고이며 개발 환경에서 재현한 결과가 아니다. 사용자 PC 보안 설정은 변경하지 않았다.

## 바뀐 흐름
영역 선택에는 대사 글자 줄과 작은 여백을 포함하고 배경·메뉴·이름 칸은 필요할 때만 포함하도록 안내한다. 모니터 높이의 35% 또는 면적의 30%를 넘으면 배경 문자가 섞일 수 있다는 참고 안내만 표시한다. 선택을 금지하거나 임의로 자르지 않는다. 900×70은 해당 게임 사례이며 모든 게임의 권장 크기가 아니다. 세로쓰기/여러 줄 게임은 그 대사 전체를 포함해야 한다.

영역을 확정하면 자동으로 로컬 OCR 미리보기를 실행한다. 번역 API 호출은 없으며 앱/오버레이를 숨긴 다음 캡처한다. 인식 결과가 잘못되면 다시 선택한다.

## 공백 처리 범위
미리보기는 OCR 반환 문자열을 그대로 보여 주고, 일본어 문자 사이의 단일 ASCII 공백에만 정리 후보를 추가한다. 여러 공백·전각 공백·줄바꿈·탭·영문/숫자 경계·문장부호 경계는 변경하지 않는다. 일본어 사이 공백도 의도된 구분일 수 있으므로 후보에는 의미 검증 안 됨/자동 적용 안 함을 표시한다.

후보는 자동 번역·안정화·중복 제거·대사 기록 경로에 넣지 않는다. 기존 번역 경로의 일반 공백 정규화 동작은 그대로다. 따라서 이번 변경은 확인 가능한 미리보기 개선이며 실시간 자막 공백이 자동 제거되는 기능은 아니다. 추후 사용자 선택 보정을 연결할 때도 원본/수정본을 구분해 기록해야 한다. 언어학적 단어 분석이나 의도 판별을 구현했다고 주장하지 않는다.

## 데모 사용량
오프라인 데모는 '모의 사용량 · 외부 전송 없음 · API 과금 없음'으로 표시한다. 로컬 번역은 '세션 처리 한도', 외부 API는 '세션 예약 사용량 (실제 청구액 아님)'으로 구분한다. 숫자만으로 요금을 추정하지 않으며 데모 카운터와 실제 청구를 혼동하지 않도록 한다.

검증은 합성 문자열·영역 치수·모드별 문구 회귀 검사다. 새 UI의 실제 Windows 게임 캡처/정확도는 별도 미검증이며 보안 설정을 바꾸지 않는다.
