## 후속 비교 기준 (목표이며 달성 수치 아님)

동일 합성 대사 100개 이상을 짧은 문장/장문/존댓말/욕설/비노골적 위협/문맥대명사로 분리. 원문 마지막 글자 안정 시각→캡처 완료→OCR 완료→안정화 확정→추론 첫 토큰/완료→UI 실제 표시를 개별 계측하고 p50/p95 및 오류율 기록. 번역 성능 목표 warm p50≤1초/p95≤2초, 전체 표시 목표 p50≤2초/p95≤4초. 현재는 이 목표 미달 또는 미측정.

cold 프로세스/첫 추론/warm/캐시 hit는 별도, CPU 1·2·4 thread와 2048·4096 context를 비교. Windows 10/11의 8GB·16GB·32GB RAM 및 AVX2 유무를 기록하고, 게임 미실행/동시 실행의 CPU·working set·commit·게임 FPS/프레임타임을 측정. 메모리 파일 크기만으로 RAM을 추정하지 않음. GPU 프로필은 장치·VRAM·드라이버 및 모델 호환 검증 전 제공하지 않음. 실제 평가 전 사양별 기본 모델을 강제하지 않음.
