# 로컬 번역 0.4 개발 후보

0.3 공개 릴리스에는 없습니다. 외부 DeepL 또는 로컬 llama.cpp를 명시적으로 선택합니다. 기본은 안전한 오프라인 데모이며 로컬 모델 기본 추천은 아직 없습니다. 로컬 오류·거부·시간 초과 때 외부 API로 전환하거나 자동 재시도하지 않습니다. 원문과 문맥을 JSON 데이터로 보내고 말투·욕설·성적/폭력적 표현의 불필요한 순화나 추가를 하지 않도록 지시합니다. 모델의 거부·환각·오역까지 없앨 수는 없습니다. 번역문을 임의로 고쳐 검증된 번역처럼 표시하지 않습니다.

## 구현 범위

설정의 제공자 선택 → 로컬 모델/연결 설정에서 모델 이름·바이트 크기·상태·계획 메모리·라이선스·측정 여부 확인 → 다운로드 동의 → 설치. 선택 모델의 공식 고정 커밋과 SHA-256/크기를 검사하고 임시 파일을 원자적으로 교체합니다. 실패/취소 시 미완성 파일 제거, 기존 손상 파일은 자동 덮어쓰지 않습니다. 모델 다운로드만 인터넷을 사용하고 인증서 검증을 유지합니다. 프록시는 모델 다운로드에서만 OS/환경 설정을 따릅니다. 네트워크 타임아웃은 30초이며 취소가 즉시 반응하지 않을 수 있습니다.

**현재 로컬 추론 엔진의 원클릭 설치/자동 시작은 미구현입니다.** 모델 선택/다운로드/삭제와 로컬 번역 연결은 구현했지만 비개발자용 완성 설치 경험은 아닙니다. 별도 공식 llama.cpp 서버가 필요합니다. Windows b12359 CPU 배포의 DLL과 OpenMP 라이선스도 확인했으나 이 후보에 묶거나 실행 검증하지 않았습니다. 서버를 임의 경로에서 자동 실행하지 않습니다.

공식 b12359 서버의 수동 CPU 예시 (선택한 GGUF 파일의 절대 경로를 지정):

```
llama-server.exe -m "C:\models\selected.gguf" --host 127.0.0.1 --port 8087 --alias kotoba-local -c 4096 -t 2 -np 1 -ngl 0 --no-webui --no-slots --cors-origins http://127.0.0.1
```

앱 포트 8087/별칭 kotoba-local로 설정하고 로컬 서버 전송 동의 후 데모를 해제합니다. Qwen3는 요청에서 enable_thinking=false를 전달합니다. 2스레드는 게임과 CPU 경쟁을 줄이기 위한 시험 시작점이지 권장 최소사양이 아닙니다. 서버는 상주하며 앱 종료로 외부 서버를 종료하지 않습니다. 해당 터미널에서 중단하세요. 이미 전송한 추론은 앱 정지 후에도 완료될 수 있으나 늦은 결과는 버립니다.

## 개인정보와 네트워크

Go는 숫자 loopback 127.0.0.1만 사용하며 DNS·프록시·리디렉션을 차단합니다. DeepL 키를 로컬 서버에 보내지 않으며 제공자 전환 시 코어의 이전 키를 지웁니다. 인식된 원문/이전 최대 3개 대사는 로컬 서버로 전달됩니다. 이미지는 전달하지 않습니다. 로컬 서버가 실제 오프라인 추론을 하는지, 로그/프롬프트 저장/클라우드 프록시 기능이 없는지는 운영자가 확인해야 합니다. 앱은 외부 서버의 동작을 보증할 수 없습니다. localhost 무인증 서비스는 같은 PC의 다른 프로세스에도 노출될 수 있습니다. 웹 UI/슬롯 노출은 끄고 신뢰하는 로컬 서버만 사용하세요.

## 모델 삭제·설치형·포터블

설치형 모델: %LOCALAPPDATA%/KotobaBridge/models. 포터블: 실행 파일 옆 data/models. 모델만 삭제 버튼은 고정 카탈로그의 파일 하나만 대상으로 합니다. 링크/정션/재분석 지점/하드링크는 거부하며 재귀 삭제는 하지 않습니다. 로컬 제공자가 선택됐거나 작업 중이면 삭제를 거부합니다. 먼저 외부 서버를 종료하고 다른 제공자를 선택하세요. 앱이 외부 서버를 소유하지 않으므로 안전한 강제 종료는 구현하지 않았습니다. 파일 잠금/권한 실패를 성공으로 표시하지 않습니다.

설치 제거의 대화형 단계는 모델 관리 창을 열지 선택하게 합니다. 선택한 모델을 지운 뒤 앱 창을 닫으면 제거가 계속됩니다. 무인 제거는 사용자 데이터를 보존합니다. API 키·settings.json·overlay.json·복습 카드는 별도로 보존하며 모델 삭제가 지우지 않습니다. 키는 메인 창의 키 지우기, 내보낸 복습 JSON은 사용자가 따로 삭제합니다. 포터블 폴더 전체 삭제 시 그 안의 모델·암호화 키·설정·카드도 함께 없어집니다. 외부 내보내기 파일은 남습니다. 제거 UI 자체와 Windows 파일 잠금 실기는 미검증입니다.
