# Kotoba Bridge — 일본어 게임 한국어 자막 기능 시제품

**최종 대상은 Windows 10 22H2 x64 / Windows 11 x64입니다. Windows 7/8 지원은 제외되었습니다.** Windows Server 2025 CI에서 미서명 설치 후보 생성·설치·오프라인 데모·제거를 검증했습니다. Windows 10/11 게임 실기·저사양 성능·정식 서명 배포는 미검증/미완료입니다. COMPATIBILITY.md에 기술 비교와 정확한 범위, packaging/에 설치본 생성 레시피가 있습니다.

Windows 우선 Go 코어 + Python/Tk 네이티브 데스크톱 UI 소스 MVP. 일본어 텍스트 어드벤처의 **가로쓰기 대사 영역**을 자동 캡처하여 로컬 OCR → DeepL 일본어/한국어 번역 → 항상 위에 있는 별도 자막 창에 표시합니다. 수동 스크린샷 저장이나 복사 반복이 필요하지 않습니다. 실제 게임 적용은 Windows 수동 인수 테스트 후 사용하세요.

OCR·일본어 모델·런타임 포함 설치형/포터블 빌드를 추가했습니다. 실제 생성 성공은 최신 Actions를 확인하세요. 일반 사용자는 개발 소스 실행 대신 INSTALLATION.md의 실행 패키지를 사용합니다. 포터블은 전체 폴더를 압축 해제하는 방식이며 EXE 단일 파일이 아닙니다.

0.2 개발 브랜치의 설치 후보·초기 설정 안내는 [INSTALLATION.md](INSTALLATION.md), 선택 가능한 후킹 입력원 검토와 미구현 범위는 [docs/TEXT_INPUT_SOURCES.md](docs/TEXT_INPUT_SOURCES.md)에 있습니다.

## 개발 소스 실행 (Windows 10/11, Python 3.14.10 이상(3.14 계열) 권장)

1. GitHub 저장소를 clone하거나 소스 ZIP을 일반 사용자 폴더에 풉니다. Python의 tkinter가 포함된 공식 Windows 설치본을 사용합니다.
2. **GitHub 소스 ZIP에는 `kotoba-core.exe`가 없습니다.** Go를 설치하고 아래 명령으로 코어를 빌드합니다. 별도로 전달된 Library 개발 번들에는 Linux에서 교차 빌드한 미서명 Windows x64 코어가 있으나 Windows 실기 미검증입니다. 정식 서명 설치본은 아직 제공하지 않습니다. PR의 미서명 개발 설치 후보에는 코어와 UI 런타임을 동봉했습니다.

```powershell
cd go-core
go build -o ../kotoba-core.exe .
cd ..
```
3. PowerShell에서 이 폴더로 이동한 뒤 실행합니다.

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

Python 3.14.10 이상(3.14 계열)이 설치되어 있다면 `setup_windows.cmd`로 위 설치와 첫 실행을 묶어 진행할 수도 있습니다. Windows 7에는 이 설치 경로를 적용하지 마세요. 다음부터 `run_windows.cmd`로 실행합니다. 첫 실행은 **오프라인 데모**입니다. 시작 버튼을 누르면 3초 후 예제 일본어 세 문장이 한국어 자막으로 반복 표시됩니다. 데모는 화면·OCR·네트워크를 사용하지 않으며 사전 정의된 번역만 보여 줍니다.

## 실제 게임 연결

1. OCR 포함 배포본은 동봉된 엔진과 `jpn.traineddata`를 초기 설정에서 확인합니다. 다음 별도 설치 절차는 개발 소스 실행/복구용입니다. 공식 설치 안내: https://tesseract-ocr.github.io/tessdoc/Installation.html . Windows 설치본은 공식 안내가 연결하는 배포처의 출처를 확인하세요. 이 ZIP에는 실행 파일·언어팩을 재배포하지 않습니다.
2. `tesseract --list-langs`에 `jpn`이 나오는지 확인합니다. PATH에 없다면 실행할 PowerShell에서 다음처럼 실제 설치 경로를 지정합니다.

```powershell
$env:TESSERACT_CMD = 'C:\Program Files\Tesseract-OCR\tesseract.exe'
.\.venv\Scripts\python.exe app.py
```

3. 게임을 창 모드 또는 테두리 없는 창으로 열고 대사를 모두 표시합니다. **창 이동, 크기 변경, DPI 변경 후 영역을 다시 설정**합니다. 좌표는 가상 데스크톱 물리 픽셀이며 왼쪽 모니터는 음수가 될 수 있습니다. 좌표 확인은 아래 PowerShell을 켜고 마우스를 대사 영역 모서리에 옮겨 읽을 수 있습니다. Ctrl+C로 종료합니다.

```powershell
Add-Type -AssemblyName System.Windows.Forms
while ($true) { [System.Windows.Forms.Cursor]::Position; Start-Sleep -Seconds 1 }
```

4. 왼쪽·위·너비·높이에 대사 상자 내부만 지정합니다. 너비=오른쪽−왼쪽, 높이=아래−위입니다. 영역은 한 모니터·한 게임 창 안에 있어야 합니다. 자막 창을 게임 대사 영역 밖으로 옮깁니다. `마우스 영역 선택`에서 로컬 화면 미리보기를 드래그할 수 있습니다. 선택 후 `로컬 OCR 미리보기`로 전송 없이 원문을 확인하세요.
5. 자신의 DeepL API 키를 마스킹 입력란에 넣고 `암호화 저장 / 교체`를 누르면 Windows DPAPI로 보관하고 입력란을 비웁니다. 다음 실행에도 키를 표시하지 않고 사용할 수 있습니다. 저장 없이 한 번만 쓰려면 입력 후 시작합니다. 데모를 해제합니다. API Free는 Pro 체크 해제, API Pro는 체크합니다. 일반 DeepL 웹 구독과 API 계정은 다를 수 있습니다.
6. 텍스트 외부 전송 안내에 동의한 뒤 시작을 누릅니다. 설정 창이 최소화되고 그 아래 게임 창을 대상으로 고정합니다. Windows에서는 시작 시 영역 중심의 창을 대상 창으로 고정하며 다른 창에 포커스가 가면 정지합니다. 영역이 브라우저 등 다른 창에 놓이지 않았는지 시작 전에 확인하세요.
7. 이 앱의 정지 버튼 또는 앱에 포커스가 있을 때 Esc로 중지합니다. Esc는 전역 단축키가 아닙니다. 게임 포커스 상실로도 다음 검사 시 정지합니다. 이미 서버로 보낸 요청은 취소할 수 없습니다.

OCR/API 오류는 자동 정지하며 자동 재시도하지 않습니다. 키 교체는 정지 후 새 키·Free/Pro 선택 → `암호화 저장 / 교체`입니다. `API 키 지우기`는 현재 데이터 폴더의 암호화 파일과 코어 키를 삭제합니다. 정상 코어의 세션 사용량은 유지됩니다. `대화 지우기`는 저장 키를 삭제하지 않습니다. 키 저장 방식과 복사본 삭제·OS 보호 한계는 [키 보관 안내](docs/KEY_STORAGE.md)를 확인하세요.

## 개인정보 및 비용

- 화면 이미지는 외부 업로드하지 않습니다. 선택 영역의 OCR 원문과 이전 최대 3개 원문(총 1,500자까지)을 DeepL에 전송합니다. 문맥은 대명사와 흐름을 돕지만 고유명사·말투 일관성을 보장하지 않습니다.
- 게임 알림이나 다른 내용이 영역 위에 겹치면 인식될 수 있습니다. 포커스 검사는 완전한 개인정보 필터가 아닙니다. 민감한 창·알림을 닫고 좁은 영역만 선택하세요. API 서비스의 현재 데이터 처리 약관은 사용자가 확인해야 합니다.
- 앱은 캡처/텍스트/키 로그와 설정 파일을 자동으로 디스크에 저장하지 않습니다. 초기 설정에서 명시적으로 저장하면 OCR 경로와 영역 좌표만 로컬 settings.json에 보관합니다. 키·전송 동의·대사는 포함하지 않습니다. 대사 기록은 메모리에만 유지하고 선택한 복습 카드만 사용자가 JSON으로 내보낼 수 있습니다. Go 코어는 PNG를 Tesseract 표준 입력으로 전달하며 앱이 OCR용 이미지 파일을 생성하지 않습니다. 엔진/OS 자체 동작과 크래시 덤프까지 통제하는 것은 아닙니다. RAM도 암호화 저장소가 아닙니다.
- 키는 명시적 저장 시 현재 Windows 사용자 범위 DPAPI 암호문으로 별도 파일에 보관합니다. 평문 저장 대안은 없습니다. 사용 시 UI/Go 메모리와 private stdio configure에 일시적으로 존재하며 물리적 영점화는 보장하지 않습니다. 키를 명령줄·환경변수·URL·로그에 넣지 않습니다. 전송 동의는 매 실행 필요합니다. HTTPS 고정 호스트와 TLS 검증을 유지하며 리다이렉트·환경 프록시·자동 재시도는 없습니다.
- 1회 최대 2,000자, 프로세스 세션 최대 10,000자/100회, 최소 3초 간격. 한도는 데모에서 실사용으로 전환해도 유지합니다. 재시작하면 리셋되므로 월간/계정 전체 비용 상한이 아닙니다. 공급자 콘솔의 사용 한도도 설정하세요. 통화 금액을 보장하지 않으며 가격을 하드코딩하지 않습니다.
- 실패·시간 초과도 요청 전 예약량을 차감하며 자동 재시도하지 않습니다. 서버에서 과금됐을 수 있기 때문입니다. 호출 간격을 기다린 뒤 화면과 포커스를 재검사합니다. 대사가 바뀌었으면 오래된 요청을 폐기합니다. API 오류 뒤 자동 재시도는 하지 않습니다.
- 문맥을 포함한 캐시 키 128개, OCR 약 0.9초 안정화, 동일 화면 중복 억제. 재개 시 안정화 상태는 초기화됩니다. 문맥이 다른 동일 문장은 재전송될 수 있습니다.

## 테스트

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

테스트는 가짜 HTTP transport와 번역기를 사용하며 **실제 유료 API를 호출하지 않습니다**. 결과·플랫폼별 검증 범위는 TEST_REPORT.md, 기획과 기술 비교는 DESIGN.md, Windows 인수 절차는 WINDOWS_CHECKLIST.md에 있습니다.

GitHub 소스에는 실행 바이너리·설치 프로그램·서명된 MSIX가 포함되지 않습니다. 별도 Library 개발 번들의 교차 빌드 코어도 설치 프로그램은 아닙니다. 이것은 설치 단계가 있는 소스 배포 MVP이며, Windows에서 검증된 완성 제품으로 표현하지 않습니다.

## 플레이와 학습 모드

별도의 작은 자막 창에 **일본어 원문 위 / 한국어 번역 아래**를 표시합니다. 기본 플레이 모드는 Windows 클릭 통과를 요청합니다(실기 미검증). 설정 창은 최소화할 수 있고 작업 표시줄로 복귀할 수 있습니다. 자막 위치를 바꾸려면 학습 모드로 전환해 제목 표시줄을 드래그하세요. 자막이 OCR 영역을 가리면 중지합니다. Linux에서는 클릭 통과를 지원하지 않습니다.

`학습 / 기록`을 누르면 요청이 종료된 뒤 학습 창을 열 수 있습니다. 원문·번역을 비교하고 일본어 단어/문장을 드래그해 `선택 저장`을 누르세요. `저장한 복습 카드 보기`로 다시 읽거나 삭제할 수 있습니다. `JSON 내보내기`를 해야 앱 종료 후에도 카드가 남습니다. 나중에 `JSON 불러오기`로 복습합니다. 기록/카드는 최대 500개입니다.

`선택 사전 열기`는 별도 확인 후 선택한 원문(최대 100자)을 네이버 일본어사전 검색어로 보내고 외부 브라우저를 엽니다. 검색어는 브라우저 기록과 네이버의 처리 대상이 될 수 있습니다. 사전 본문을 수집·내장·재배포하지 않습니다. 한국어 뜻은 외부 사이트에서 확인하며 문장·활용형에는 적합한 결과가 없을 수 있습니다. 자동 분석·후리가나·내장 사전은 미구현입니다.

`플레이로 복귀`로 클릭 통과를 복구한 뒤 시작 버튼과 게임 클릭으로 번역을 재개합니다. 학습 창은 자동으로 열리지 않습니다. 게임 중 자동 복습 알림도 없습니다.

대화 지우기는 번역 문맥/캐시만 지웁니다. 학습 창의 `기록·카드 전체 비우기`는 메모리의 학습 데이터까지 지웁니다. 내보낸 JSON은 평문이며 탐색기에서 별도 삭제해야 합니다. 브라우저 사전 검색 기록도 별도입니다. 보관/전송 경계와 사전 라이선스 자료는 DESIGN.md에 있습니다.

프로세스 분리와 통신 규약은 ARCHITECTURE.md, 변경 경위는 CHANGELOG.md를 참고하세요. Windows 설치본은 packaging/의 레시피를 Windows에서 빌드·검증·서명해야 하며, Windows installer candidate CI에서 미서명 설치 후보와 설치/제거 검사 보고서를 생성합니다. 빌드 성공 여부는 해당 PR의 Actions 결과를 확인하세요. 새 빌드는 소스에서 빌드한 OCR과 일본어 모델을 포함하고 필수 OCR self-test를 통과해야 artifact를 제공합니다. 기존 OCR 미포함 후보와 구분하세요.

## 외부 원문 입력과 후보 선택 체험

`외부 원문 붙여넣기 / 후보 선택 체험`은 OCR을 정지한 뒤 사용자가 클립보드를 한 번 읽거나 원문을 직접 입력하는 창입니다. Textractor의 Copy to Clipboard 출력처럼 별도 도구에서 복사한 텍스트를 확인한 후 `확인한 원문 1회 번역`을 누르면 메인 화면의 키와 전송 동의, 기존 세션 한도를 사용합니다. 매번 별도 확인을 받고 이전 번역 문맥을 지웁니다. OCR로 복귀할 때도 수동 원문 문맥을 지우며 세션 예산은 유지합니다. 이미지·합성 후보는 전송하지 않으며 클립보드의 게임 출처는 인증하지 못합니다. 자동 감시·자동 재시도는 없습니다. 입력 수정/닫기/정지는 늦은 응답을 폐기하지만 이미 전송된 요청의 과금을 취소하지 못합니다. 요청 간격 제한 오류 후에는 기다렸다가 사용자가 다시 눌러야 합니다.

합성 후보 체험은 이름·잡음·대사 예제를 로컬에서 추천 순서로 보여 주며 사용자가 선택합니다. **실제 후킹 후보 탐색이나 게임 주입 기능이 아닙니다.** 실제 연동의 인터페이스/GPL 경계는 [조사 문서](docs/TEXT_INPUT_SOURCES.md)에 있습니다. 게임별 프로필 저장·Luna WebSocket 접속도 미구현입니다.

초기 설정의 `단계별 설치 도움말`은 공식 문서가 안내하는 제3자 Windows OCR 배포처, 일본어 구성, 전용 설치 폴더와 재검사 순서를 제공합니다. 자동 다운로드·설치·보안 우회는 하지 않습니다. [무결성·라이선스 검토](docs/OCR_INSTALLATION.md)를 참고하세요.

## 자막 배경 설정

Windows에서는 `자막 배경 불투명도`를 0–100%로 조절하고 `배경 설정 저장`으로 유지합니다. 글자 창은 항상 alpha=1이며 별도 배경 창만 흐려집니다. `자막 표시 / 위치·배경 복구`는 숨김·화면 밖 위치를 복구하고 배경을 85%로 되돌립니다. 플레이는 클릭 통과, 학습은 글자 선택 모드입니다. 색상 키로 비운 부분은 학습 중에도 클릭이 아래로 갈 수 있으므로 안정적인 선택에는 학습 기록 창을 사용하세요. Windows 게임·DPI·자막 가장자리 품질은 미검증입니다. 다른 OS는 불투명 배경이며 전체 글자 alpha로 흉내 내지 않습니다. [합성 방식과 제약](docs/OVERLAY.md)


## 로컬 번역 개발 후보

외부 DeepL과 선택 가능한 로컬 llama.cpp 제공자, 고정 모델 다운로드·개별 삭제를 추가했습니다. 아직 별도 서버 실행이 필요한 시험 기능으로 비개발자용 원클릭 엔진 설치는 미완성입니다. 1.5B 합성 시험에서 오역이 많아 기본 모델로 추천하지 않습니다. [설정·라이선스·삭제](docs/LOCAL_TRANSLATION.md), [실측과 한계](docs/LOCAL_PERFORMANCE.md)를 확인하세요. 공개 0.3 릴리스에는 이 변경이 없습니다.

### 실험적 실제 후킹 입력

`실험: Textractor 후킹 입력`에서 별도로 설치한 공식 5.2.0 CLI와 게임 프로세스를 직접 선택하고 연결에 동의할 수 있습니다. 엔진의 기존 자동 인식 후보를 로컬 미리보기·선택한 뒤 확인한 원문을 1회 번역합니다. 실제 게임 호환성·정상 해제는 미검증이며 구형 엔진의 통신 권한 한계가 있어 기본 권장/동봉 엔진은 아닙니다. 선택 후보 연속 번역은 별도 동의로 켤 수 있고 중복/최신 대사/포커스/정지 가드를 적용합니다. 광범위 후크 탐색·게임별 프로필은 미구현입니다. 보호 없는 합성 프로그램 CI 결과와 라이선스·무결성·종료 경계는 [후킹 CLI 안내](docs/HOOK_CLI.md)를 확인하세요. 이전 합성 후보 체험 UI와 실제 CLI 연결 UI는 별개입니다.

### DeepL 계정 사용량

실제 DeepL 번역 시작 또는 정지 상태의 `DeepL 계정 사용량 새로고침`으로 API 조회값과 한도·조회 시각을 표시합니다. 데모/로컬에서는 호출하지 않습니다. 반영에 몇 분 걸릴 수 있고 조회 실패 시 추정치로 대체하지 않습니다. 앱 내부 안전 세션 제한은 별도로 유지합니다. [조회 범위와 오류 처리](docs/ACCOUNT_USAGE.md).
